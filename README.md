🎨 Design Philosophy

The ASON login portal draws inspiration from cyberpunk and sci-fi aesthetics, creating an immersive experience that communicates security and advanced technology. The color palette combines:

· Neon Blue (#00f0ff): Represents technology, security, and the digital realm
· Hot Pink (#ff2a7a): Adds contrast, draws attention to key actions
· Dark Purple (#0b0614): Creates depth and mysterious atmosphere

🎨 Customization

Changing Colors

Modify the CSS variables in the <style> section:

```css
:root {
    --primary-neon: #00f0ff;
    --primary-pink: #ff2a7a;
    --dark-bg: #0b0614;
    --dark-surface: #11081a;
    --text-primary: #ffffff;
}
```

Updating Social Icons

The social login section currently shows Google, GitHub, and Discord. To modify:

```html
<div class="social-icons">
    <a href="#" class="icon-circle"><i class="fab fa-google"></i></a>
    <a href="#" class="icon-circle"><i class="fab fa-github"></i></a>
    <a href="#" class="icon-circle"><i class="fab fa-discord"></i></a>
</div>
```

Replace fa-google, fa-github, or fa-discord with any Font Awesome brand icon.

Form Action

Update the form action to your backend endpoint:

```html
<form action="/api/auth/login" method="POST">
```
